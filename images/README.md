# TabBar 图标说明

## 所需图标文件

请在此目录下放置以下图标文件：

### 首页图标
- `home.png` - 首页未选中图标
- `home-active.png` - 首页选中图标

### 房间图标
- `room.png` - 房间未选中图标  
- `room-active.png` - 房间选中图标

### 账单图标
- `bill.png` - 账单未选中图标
- `bill-active.png` - 账单选中图标

### 个人中心图标
- `user.png` - 个人中心未选中图标
- `user-active.png` - 个人中心选中图标

## 图标规格要求

- 尺寸：78px * 78px（推荐）
- 格式：PNG（支持透明背景）
- 颜色：未选中状态建议使用灰色系，选中状态使用品牌色
- 文件大小：建议控制在40KB以内

## 临时解决方案

如果暂时没有图标文件，可以：
1. 在app.json中临时注释掉tabBar配置
2. 或者使用微信内置的图标字体
