## 需求和项目描述

具体实现逻辑具体按已实现的项目代码为准

轻量级房租管理工具，帮助个人房东管理房产和收租。采用"线下签约、线上管理"模式。

我在设计一个轻量级房租管理系统，目标群体是房东和租客。目的是为了让房东更轻松便捷地管理他房子。从房屋管理，到水电抄表，开收据，再到数据统计等。以下是需求简介：1.房屋管理需要做到楼栋（公寓/楼）概念，并且每座楼栋有多个房间的概念，楼栋可编辑简单信息（名称，层数，地址）。

2.可以给房间命名可以描述房间类型。出租功能：房间可以编辑出租信息和出租状态， 出租信息有租期 押金 租金 交租日期 卫生费 电费 水费 和其他条款补充概念，以及租客信息（姓名电话（可选））。退房功能：根据抄表后结算费用生成收据账单

3.水电抄表管理，当配置好房屋和房间后，可以关联到房间号进行水电抄表记录，可以查看房号的历史抄表记录抄表时间 

4.收据（账单）管理。抄表完成后可以根据已出租的房屋合同信息计算收据，收据单上呈现必要的信息（房号，日期，水电用量和单价，月租，其他费用等），生成的数据支持修改；支持直接开单功能，填写必要信息和费用即可生成账单；前端样式参考常用直观易懂的收据单。一键编辑和查询未交租/已交租状态的收据 。

5.个人界面：简洁，点击支持授权头像和昵称，楼栋管理按钮等

## 数据模型

根据云函数代码，梳理出以下核心数据模型（数据库集合）：

### 1. `buildings` - 楼栋

管理房东的楼栋信息。

- `_id: string` - 主键
- `name: string` - 楼栋名称 (如: A栋)
- `address: string` - 地址
- `floors: number` - 总层数
- `landlordId: string` - 房东的用户OpenID
- `createdAt: Date` - 创建时间
- `updatedAt: Date` - 更新时间

### 2. `rooms` - 房间

核心实体，管理每个房间的详细信息、租客和费用配置。

- `_id: string` - 主键
- `buildingId: string` - 所属楼栋ID (关联 `buildings`)
- `buildingName: string` - 所属楼栋名称 (冗余字段)
- `roomName: string` - 房间号 (如: 101)
- `status: number` - 出租状态 (1: 空置, 2: 已出租)
- `monthlyRent: number` - 月租金
- `waterPrice: number` - 水费单价 (元/吨)
- `electricityPrice: number` - 电费单价 (元/度)
- `cleaningFee: number` - 保洁费
- `lastWaterReading: number` - 初始或上次水表读数
- `lastElectricityReading: number` - 初始或上次电表读数
- `tenantId: string` - 租客ID (可选)
- `tenantName: string` - 租客姓名 (可选)
- `tenantPhone: string` - 租客电话 (可选)
- `landlordId: string` - 房东的用户OpenID
- `createdAt: Date` - 创建时间
- `updatedAt: Date` - 更新时间

### 3. `meter` - 抄表记录

记录每个房间每月的水电抄表数据。

- `_id: string` - 主键
- `roomId: string` - 房间ID (关联 `rooms`)
- `readingMonth: string` - 抄表月份 (格式: 'YYYY-MM')
- `waterReading: number` - 本次水表读数
- `electricityReading: number` - 本次电表读数
- `prevWaterReading: number` - 上次水表读数 (用于计算)
- `prevElectricityReading: number` - 上次电表读数 (用于计算)
- `waterUsage: number` - 本月用水量
- `electricityUsage: number` - 本月用电量
- `recordDate: string` - 抄表日期 (格式: 'YYYY-MM-DD')
- `images: Array<string>` - 抄表照片 (可选)
- `landlordId: string` - 房东的用户OpenID
- `createdAt: Date` - 创建时间
- `updatedAt: Date` - 更新时间

### 4. `bills` - 账单

根据抄表记录和房间租金生成的月度账单。

- `_id: string` - 主键
- `billNo: string` - 账单编号
- `roomId: string` - 房间ID (关联 `rooms`)
- `meterReadingId: string` - 抄表记录ID (关联 `meter`)
- `billMonth: string` - 账单月份 (格式: 'YYYY-MM')
- `rentAmount: number` - 租金费用
- `waterAmount: number` - 水费
- `electricityAmount: number` - 电费
- `cleaningAmount: number` - 保洁费
- `totalAmount: number` - 总金额
- `status: number` - 账单状态 (1: 待支付, 2: 已支付)
- `paidAmount: number` - 已支付金额
- `tenantId: string` - 租客ID
- `tenantName: string` - 租客姓名
- `tenantPhone: string` - 租客电话
- `landlordId: string` - 房东的用户OpenID
- `createdAt: Date` - 创建时间
- `updatedAt: Date` - 更新时间
