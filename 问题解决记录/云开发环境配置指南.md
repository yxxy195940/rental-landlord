# 🌩️ 微信云开发环境配置指南

## 🔍 问题原因
"cloudfunctions显示未选择环境" 表示微信云开发环境还没有正确配置或创建。

## 📋 解决步骤

### 第1步：在微信开发者工具中开通云开发 ⭐

1. **打开微信开发者工具**
2. **导入项目**：选择当前目录
3. **点击云开发按钮**：
   - 在工具栏找到 `云开发` 按钮
   - 或者点击 `工具` → `云开发`
4. **开通云开发**：
   - 首次使用会提示开通云开发
   - 选择 `开通`
   - 按照提示填写信息

### 第2步：创建云环境

1. **创建环境**：
   - 环境名称：`rental-system-env`（或其他名称）
   - 环境ID会自动生成，如：`cloud1-2gy34tuh656ffa81`
2. **等待环境创建完成**（可能需要几分钟）

### 第3步：更新环境配置

环境创建完成后，更新配置文件中的环境ID：

#### app.js 配置
```javascript
wx.cloud.init({
  env: 'your-env-id', // 替换为实际的环境ID
  traceUser: true
})
```

#### project.config.json 配置
```json
{
  "cloudfunctionRoot": "cloudfunctions/",
  "cloudbaseEnv": "your-env-id"
}
```

### 第4步：验证配置

1. **重启微信开发者工具**
2. **查看云开发控制台**：
   - 点击 `云开发` 按钮
   - 应该能看到环境信息
3. **检查云函数面板**：
   - cloudfunctions 目录不再显示"未选择环境"

## 🚨 常见问题

### 问题1：找不到云开发按钮
- **解决**：确保使用最新版本的微信开发者工具
- **解决**：检查小程序 AppID 是否正确

### 问题2：开通失败
- **原因**：小程序未发布或AppID权限不足
- **解决**：
  1. 确保小程序已经在微信公众平台注册
  2. 确保账号有云开发权限
  3. 联系小程序管理员开通权限

### 问题3：环境创建失败
- **解决**：检查网络连接
- **解决**：重试几次，服务器可能繁忙
- **解决**：更换环境名称

### 问题4：配置后仍显示"未选择环境"
- **解决**：重启微信开发者工具
- **解决**：检查 cloudfunctionRoot 路径是否正确
- **解决**：确认环境ID是否正确
