# 🧪 云函数调用测试指南

## 🎯 测试目标
验证云函数 `room` 是否能正常调用，以及与数据库的交互是否正常。

## 📋 测试步骤

### 第1步：在微信开发者工具控制台测试

#### 方法1：直接在控制台调用
在微信开发者工具的 Console 面板中输入：

```javascript
// 测试获取房间列表
wx.cloud.callFunction({
  name: 'room',
  data: {
    action: 'list',
    page: 1,
    pageSize: 10
  },
  success: res => {
    console.log('云函数调用成功:', res)
  },
  fail: err => {
    console.error('云函数调用失败:', err)
  }
})
```

#### 方法2：测试添加房间
```javascript
// 测试添加房间
wx.cloud.callFunction({
  name: 'room',
  data: {
    action: 'add',
    roomData: {
      roomNumber: '101',
      address: '测试地址',
      rent: 1500,
      deposit: 1500,
      area: 25,
      isRented: false
    }
  },
  success: res => {
    console.log('添加房间成功:', res)
  },
  fail: err => {
    console.error('添加房间失败:', err)
  }
})
```

### 第2步：在页面中集成测试

#### 修改配置启用云函数
```javascript
// utils/config.js
export const config = {
  useCloud: true, // 改为 true 启用云函数
  // ...其他配置
}
```

#### 测试房间列表页面
1. 打开房间列表页面
2. 查看控制台日志
3. 观察数据是否正常加载

### 第3步：云开发控制台测试

#### 在云开发控制台测试云函数
1. 打开 **云开发控制台**
2. 点击 **云函数**
3. 找到 `room` 函数，点击 **测试**
4. 输入测试数据：
```json
{
  "action": "list",
  "page": 1,
  "pageSize": 10
}
```
5. 点击 **运行测试**

## 🔍 常见问题排查

### 问题1：云函数调用失败
- **原因**：环境配置错误
- **解决**：检查 app.js 中的环境ID是否正确

### 问题2：权限错误
- **原因**：数据库权限配置问题  
- **解决**：在云开发控制台设置数据库权限

### 问题3：数据为空
- **原因**：rooms 集合不存在或为空
- **解决**：在云开发控制台创建 rooms 集合

### 问题4：网络超时
- **原因**：网络连接问题
- **解决**：检查网络连接，重试几次

## 💡 测试技巧

1. **先测试简单功能** - 从数据库查询开始
2. **观察控制台日志** - 查看详细错误信息  
3. **检查云函数日志** - 在云开发控制台查看云函数日志
4. **逐步测试** - 不要一次运行所有测试
5. **保存测试结果** - 点击结果可复制详细信息
