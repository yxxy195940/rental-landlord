# 房租管理系统云开发迁移指南

## 迁移完成情况

✅ **已完成的工作**：

1. **云开发环境配置**
   - 在 app.js 中初始化云开发
   - 创建 cloudfunctions 目录
   - 配置 project.config.json

2. **双轨运行配置**
   - 创建 utils/config.js 配置文件
   - 支持 `useCloud` 开关切换运行模式

3. **请求层改造**
   - 修改 utils/request.js 支持云函数和API双轨调用
   - 保持原有API调用方式的兼容性

4. **room 云函数实现**
   - 创建完整的房间管理云函数
   - 支持获取房间列表、创建、更新、删除等操作
   - 数据格式与原API保持一致

5. **前端页面适配**
   - 修改 pages/rooms/rooms.js 支持配置切换
   - 保持原有功能不变

## 使用方法

### 1. 配置切换

在 `utils/config.js` 中修改 `useCloud` 参数：

```javascript
export const config = {
  useCloud: true,  // true: 使用云开发, false: 使用传统API
  // ... 其他配置
}
```

### 2. 云环境设置

需要在微信开发者工具中：

1. 开通云开发服务
2. 创建云环境（环境ID: `rental-system-env`）
3. 创建云数据库集合：`rooms`
4. 部署云函数：右键 `cloudfunctions/room` 选择"上传并部署"

### 3. 数据结构

云数据库 `rooms` 集合字段映射：   

| 云数据库字段 | 原API字段 | 说明 |
|-------------|-----------|------|
| _id | id | 房间ID |
| roomName | roomNumber | 房间编号 |
| propertyName | location | 位置信息 |
| landlordId | - | 房东openId |
| status | status | 房间状态 |
| tenantName | tenantName | 租客姓名 |
| tenantPhone | tenantPhone | 租客电话 |
| monthlyRent | monthlyRent | 月租金 |

## 调试方法

云函数执行日志在微信开发者工具的"云开发"面板中查看。

### 2. 前端调试

在配置文件中启用调试：

```javascript
debug: {
  enabled: true,
  logLevel: 'info',
  showCloudFunctionLogs: true

```

### 3. 常见问题

**云函数调用失败**：
- 检查云环境ID是否正确
- 确认云函数已正确部署
- 查看云函数执行日志

**数据格式不匹配**：
- 检查云函数中的数据转换逻辑
- 对比API和云函数的返回格式

## 配置示例

完整的配置文件示例：

```javascript

  useCloud: true, // 切换到云开发模式
  
  cloudConfig: {
    env: 'rental-system-env',
    timeout: 10000,
    retryCount: 2,
  },
  
  apiConfig: {
    baseUrl: 'https://api.rental.com',
    timeout: 10000,
    retryCount: 3,
  },
  
  debug: {
    enabled: true,
    logLevel: 'info',
    showCloudFunctionLogs: true,
  }
}
```
